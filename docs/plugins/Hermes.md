# Hermes

Starts off. Set up Hermes only if you want an agent that stays on.

1. Set up your own Hermes agent. Give it one small job and the files that job needs.
2. Try a job that reads and writes only in your work folder. It can collect notes, run a task on a schedule, or spot work that has stopped.
3. Have it send one note to the COO or save one note where the COO can read it. The COO still hands out jobs and writes the CEO outbox.
4. Let it run on a schedule after you check the test. Stop its jobs in Hermes when you want to turn it off.
