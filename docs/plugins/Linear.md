# Linear

Starts off. Use Linear if you want a ticket for each job.

1. Pick a project you can use. Link your own account or a team bot.
2. Check who will post before you let the COO write to a ticket.
3. Link each ticket in the COO work list. Put the goal, check, and result on the ticket.
4. Follow [the 80/20 writing rules](../writing.md) for every AI-written issue, comment and update. Put the result first. Link the evidence and name the next action or blocker.
5. Workers report to the COO. The COO writes one CEO outbox and uses only the team's approved Linear identity. Remove ticket access when you want to turn it off.
