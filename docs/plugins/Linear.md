# Linear

Starts off. Use Linear if you want a ticket for each job.

1. Pick a project you can use. Link your own account or a team bot.
2. Check who will post before you let the COO write to a ticket.
3. Link each ticket in the COO work list. Put the goal, check, and result on the ticket.
4. Workers still report only to the COO. The COO still writes one CEO outbox. Remove ticket access when you want to turn it off.
