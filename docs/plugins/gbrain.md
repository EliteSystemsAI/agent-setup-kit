# gbrain

Starts off. Use gbrain if you want to search more project notes.

1. Set up a gbrain space you own and add notes you can share with this team.
2. Give your agents read access. Put the search link or command in their handoffs. Try a search for a fact you know is in the notes.
3. Use the search to find sources. Send new facts to the Notion inbox for review. Keep the active facts in Notion.
4. Remove the search link from your work notes when you want to turn it off.
