# Swap tools or accounts

1. Ask the old chat to save `HANDOFF.md`. It writes the goal, state, next step, and a short log. Save any file edits and note the project path, branch, and tests. If the chat stopped, start from the last saved note and check the files or branch for newer work.
2. Stop the old chat from taking more work. Tell the COO when a worker is moving. Keep one writer for that job.
3. Open a fresh chat in the other tool or account. Use the same work folder. If you move to a new device, copy the private work folder and make sure the new chat can reach the project files. Set up Notion access on that device with your own token.
4. Give the new chat the same role prompt and handoff path. A worker also reads its `TASK.md`. Ask it to read the saved notes and active Notion facts, check that the state still matches the files, and pick up from Next.
5. The fresh chat writes a short log entry when it takes over. A worker reports the switch to the COO.

You can use this process for the CEO, the COO, or a worker. The chat log can stay in the old account.
